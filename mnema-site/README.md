# MNEMA — Skin Has A Memory

A static luxury skincare brand identity site for MNEMA.

## What's new in this edition
- Replaced the repetitive hero/manifesto/identity visuals with three dedicated MNEMA brand images.
- Added a dedicated **Brand Typography** section with display, sans-serif and mono systems.
- Updated the identity panel to use the current MNEMA wordmark direction.
- Corrected the toner/tinted-serum image mapping.
- Removed the visible product sequence numbers from the product photography while retaining product names and sizes in the website UI.
- Kept the visual language restrained: Obsidian, Memory Bone, Aged Champagne, Deep Oxide and Mineral.

## Run
Open `index.html` directly in a browser. No build step is required.
